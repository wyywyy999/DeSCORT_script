DeSCORT Documentation
=====================

DeSCORT learns morphological representations from Cell Painting profiles and supports
perturbation retrieval, virtual-cell prediction, and biological analysis.

Start with installation, then follow the task-specific tutorials. Data, vocabularies,
and model checkpoints must be prepared separately as described in each tutorial.
