# 复现约定

本次整理未重跑论文全部训练。安装、CPU 合成链路、现有小样本测试与命令行检查的结果见整理验证报告，不能替代真实 GPU 训练或论文指标复现。

每次实验保存：路径配置、最终 argv、种子、环境版本、模型 `config.json`、数据划分、特征集合/顺序、词表与条件向量的校验值、检查点与输出目录。示例配置会显式覆盖部分参数，是使用示例，不是原论文最终超参数。

必须特别保持：

1. `DataArguments`、`ModelArguments`、模型配置和 Bash 参数分别有自己的默认值。例如 `marginal_quantile_weight` 在参数类与模型配置中的默认值不同，应保存最终有效值。
2. 空文件筛选列表保留原实现含义；不要擅自替换为某组 plate。
3. 生物学 UMAP 的查询近邻分析只在显式指定查询基因时执行，避免改变原有流程。
4. virtual-cell 的 unseen 扰动与跨细胞系任务分别记录训练/测试条件、是否 few-shot、控制抽样和特征轴。
5. 连续形态数据的差异检验、PDS、表达/分布指标使用现有 `vc` 定义；选择 legacy 与 VCC2026 指标族时写明口径。
6. 基线需使用相同评估输入、扰动集合、feature axis、对照规则和样本/群体聚合定义。

原项目的输出目录只作为历史结果读取来源；新实验建议全部写到新仓库的 `outputs/` 或专用外部新目录。
